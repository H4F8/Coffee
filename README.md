# Кафе «Полдень»

Одностраничный сайт кафе с меню, корзиной, бронированием столика и адаптивной версткой.

## Запуск локально

Требуется установленный Node.js.

```powershell
node server.js
```

Откройте в браузере: <http://localhost:3000>

## Структура

- `index.html` — разметка страницы
- `css/styles.css` — стили
- `js/main.js` — меню и интерактивная логика
- `server.js` — простой локальный сервер для разработки

Проект не использует npm-зависимости, `.env` и серверную базу данных.
